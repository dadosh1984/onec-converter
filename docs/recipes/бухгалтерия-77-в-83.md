# Пример: «Бухгалтерия 7.7 → Бухгалтерия 8.3» (Фаза 53, U53)

Готовый сценарий миграции данных из файловой ИБ «1С:Бухгалтерия 7.7»
(1Cv77.dat) в файловую ИБ «1С:Бухгалтерия 8.3» (1Cv8.1CD) без платформы 1С.
Переносятся данные (справочники, документы, регистры); конфигурация
приёмника остаётся «родной» и берётся за основу.

## Предпосылки

- `onec-converter` установлен (`pip install -e .`), источник — каталог
  с `1Cv77.dat`, приёмник — каталог с `1Cv8.1CD` (приёмник не изменяется,
  пишем в копию или через HTTP-сервис).

## Шаги

```bash
# 1. Структура источника (7.7)
onec-converter inspect --source-dir ./src77      # справочники/документы/регистры

# 2. Список таблиц и размеры приёмника (8.3)
onec-converter stats --source-dir ./dst83

# 3. Сверка структур (что есть в приёмнике под нужные виды)
onec-converter compare-structures --source-dir ./src77 --target-dir ./dst83

# 4. Экстракт остатков регистров из 7.7 (потоково)
onec-converter extract --source-dir ./src77 --objects "Регистр.*" \
    --out ./regs.json

# 5. Правила: авто-маппинг 7.7-объектов на таблицы приёмника
onec-converter ai-map --source-dir ./src77 --target-dir ./dst83 \
    --objects "Справочник.*,Документ.*,Регистр.*" --out ./rules.json

# 6. Трансформация (маппинг полей по TOON)
onec-converter transform --input ./regs.json --rules-file ./rules.json \
    --out ./regs-mapped.json

# 7. Загрузка в файловый приёмник (прямая запись, копия)
onec-converter load --input ./regs-mapped.json --direct --target-dir ./dst-copy

# 8. Сверка полноты переноса
onec-converter verify --input ./regs.json --target ./regs-mapped.json --json
```

## Заметки

- Прямая запись (`--direct`) работает в **append-режиме** (добавление к
  существующим данным копии); для чистого переноса начните с `clone-db`.
- Выборки по разделам: `--objects "Справочник.Контрагенты"` (см. extract).
- Комплаенс-журнал: `audit --csv-out` и целостность `audit-verify --cross-files`.
