      обновить индекс (пересоздать листья из полных ключей таблицы);

- [x] [fact] Unit-тесты: индекс-объект читается/пишется; после append
      в таблицу с индексом ключи новых строк присутствуют

      реальной 8.1 → парсер + индекс читают согласованно
- [x] [assumption] README/docs: ограничение «индексы не пересобираются»
      → «индексы пересобираются, кроме BINARYDATA»
