# Контракт расширения onec_loader (детально)

## GET /metadata
Возвращает JSON: {"Справочники": [{"Имя","Синоним","Реквизиты":[...]}],
 "Документы": [...], "Перечисления": [...]}. Используется inspect_target
(резервно — прямое чтение 1Cv8.1CD приёмника нашим парсером).

## POST /load
Тело (JSON):
{"source_ib": "<id источника>", "target_ib": "<id приёмника>",  // правило 1→1
 "objects": [{"type": "...", "key": [...], "attributes": {...}, "references": {...}}],
 "replace": false}
- references: {"Реквизит": {"ref": "Справочник.Банки:0001|Банк"}} — разрешаются
  по естественному ключу на приёмнике (поиск по коду/наименованию).
- Ответ: {"ok": true, "created": N, "updated": M, "errors": [...]}
- Несовпадение source_ib/target_ib с зарегистрированной парой -> 409.

## Безопасность
- Доступ к сервису — только из доверенной сети (локальный хост);
  при необходимости — базовая аутентификация (поле Авторизация в HTTP-сервисе).
