# Spec: resolve_ref_meta

## Purpose
Расширить `load_8x.load_direct` (zero-setup А) со справочников на документы
со ссылками (REF-поля `_FLD...RREF`) и табличными частями (`_VT`-таблицы),
безопасно и честно учитывая ограничение Фазы 14 (индексы не пересобираются).

## Requirements
- [REQ-1] REF-запись: REF-поля базовой строки заполняются `_IDRREF` приёмника
  по естественному ключу из `references`; ненайденный ref → 16 нулей + отчёт.
- [REQ-2] Табличные части: базовая строка + строки `_<Base>_VT<num>` с
  `_<Base>IDRREF`=parent idref и `_LINENO<num>`=порядковый; `_KEYFIELD`=0.
- [REQ-3] Документ-база: `_NUMBER` из key/атрибута `Номер`; `_DATE_TIME`,
  `_POSTED`, `_NUMBERPREFIX` из атрибутов или нули.
- [REQ-4] Отчёт `load_direct`: `ref_warnings`/`errors` для ненайденных ссылок
  (не прерывает пакет).
- [REQ-5] Документация: `docs/format-8x.md` раздел «Ссылки и табличные части
  (Фаза 15)»; отметить, что индексы (в т.ч. VT) не пересобираются (Фаза 14).
- [REQ-6] Ворота: pytest, ruff, mypy strict, vitest зелёные; запись только на
  копиях (LockError остаётся).
