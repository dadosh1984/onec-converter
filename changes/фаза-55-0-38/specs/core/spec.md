# Spec: core

## Назначение
Фаза 55 (0.38.0): интерактивность и UX. Реализовать человек-читаемый вывод: (F1/F2) для TTY вместо сырого JSON печатать ASCII-таблицу в inspect, query, guid-diff, dump-records (через --pretty/auto-TTY, JSON остаётся при --json/не-TTY); (F3) прогресс-бар в stderr для длинных load/extract; (F4) сгруппировать аргументы через argparse argument groups; (G1/G3) сгруппировать 31 подкоманду по категориям в --help и сгруппировать редкоиспользуемые (sonar-report, export-kd3, mint-token, config-versions, metrics) в группу tools. Баланс: не переусердствовать, не сломать существующие JSON-выводы и тесты, ворота green, все тесты быстрые. Если какая-то часть рискованна/дорога — честно отметить как нет-оп.

## Область

- В области: указанная возможность, поставляется тест-первой.
- Вне области: всё, что не заявлено в предложении.
