# Spec: core

## Назначение
Провести глубокий и честный аудит проекта onec_converter на предмет ошибок, багов, мертвого кода, дублей, хардкодов, проблем с функциональностью, производительностью и востребованностью. Результат — честный список до 500 улучшений (навыки, команды, рефакторинг кода, файлы, новые функции, оптимизация). Убедиться, что весь CLI-вывод человек-читаемый (не JSON), проект интерактивен и визуально понятен пользователю. Оптимизировать количество команд/фич. Затем составить поэтапный план реализации из фаз, каждая фаза из задач. Ничего не выдумывать — только реально найденные проблемы.

## Область

- В области: указанная возможность, поставляется тест-первой.
- Вне области: всё, что не заявлено в предложении.
