# Spec: spike_docs_format

## Purpose
Не реализовывать запись пересобранного индекса (старый image-формат не
расшифрован, валидация 1С невозможна). Вместо этого задокументировать
найденный формат объекта индекса в docs/format-8x.md и закрепить его
тестом, не меняя поведения `append_records`.

## Description
Объект индекса `Table.index_page` в реальных базах 8.1/8.3 — FAT-объект без
сигнатуры `1c fd`, из N страниц: page0 — каталог границ листьев (uint32,
кумулятивные счётчики записей), нечётные страницы — описатели образов
([idx][offset]), чётные — image-страницы листьев (заголовок count:u16,
битовая дельта-упаковка ключей, payload в хвосте страницы). Формат отличен
от LeafPageHeader Tool1CD; битовая упаковка не расшифрована.

- [ ] tests/test_8x_index_format.py: документирует формат (каталог границ,
