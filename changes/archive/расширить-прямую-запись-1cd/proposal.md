# Proposal — расширить-прямую-запись-1cd

**Goal:** Расширить прямую запись в 1CD (load_8x.load_direct, zero-setup, Фаза 13) со справочников на документы со ссылками (REF-поля) и табличными частями (_VT-таблицы _Reference_*_VT... / _Acc...VT...). Нужно: spike-документация формата REF-полей (16 байт _IDRREF, пустой ref = нули) и RC/VT-таблиц (привязка к базовой строке через parent + порядковый номер) в docs/format-8x.md; факт: запись REF-полей в load_8x.py — резолв references → существующий _IDRREF приёмника (через read_dbnames или префикс), отсутствующий ref → отчёт; факт: табличные части — базовая строка объекта + строки _VT-таблиц (parent + порядковый номер); unit-тесты REF-записи, табличных частей, отсутствующего ref → ошибка/пропуск с отчётом; интеграционный тест e2e 7.7 → transform → load_direct документа со ссылками и табличной частью → парсер читает согласованно, verify; README/docs — снять ограничения MVP по ссылкам/ТЧ. Учитывать, что после Фазы 14 запись индексов НЕ реализована (append в индексированные таблицы даёт UserWarning, ключи новых строк в индексе не появляются) — подчеркнуть это ограничение в документации Фазы 15, но не блокировать REF/VT-расширение. — Python (onec_converter, load_8x.py, docs/format-8x.md)
