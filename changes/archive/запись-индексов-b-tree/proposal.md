# Proposal — запись-индексов-b-tree (РЕВИЗИЯ, Вариант A)

**Goal:** Пересмотреть Фазу 14: reverse-engineering реальных баз (8.1/8.3)
показал старый image-формат объекта индекса (`index_page`), отличный от
документированного в spike/tool1cd; битовая упаковка ключей не расшифрована,
валидация пересобранного индекса в реальной 1С невозможна, запись вслепую
рискует целостностью копии. **Решение: НЕ реализовывать запись индекса.**
Задокументировать найденный формат в docs/format-8x.md (spike-раздел:
page0-каталог границ uint32, описатели образов, image-страницы листьев,
версии, отсутствие `1c fd`), закрепить знание тестом tests/test_8x_index_format.py,
честно оставить UserWarning в `append_records` и ограничение «индексы не
пересобираются» как осознанное решение. Поведение записи не меняем.

- Platform: Python (onec_converter, write_8x.py, docs/format-8x.md)
- Constraints: Запись только на копиях; реальные базы read-only; ворота mypy strict, ruff, pytest, vitest.
- Budget: compact
