# Spec: parser-1cd

## Purpose
Полный собственный парсер файловой ИБ 1С 8.x (`1Cv8.1CD`) без платформы 1С и без
сторонних библиотек: каталог таблиц (root-объект, цепочки блоков FAT level 0/1),
строки с декодированием полей (NVC=UTF-16LE, RV=GUID, N=BCD, DT=7 байт, L=1 байт;
PARTNO отсутствует в 8.1-эпохах), blob-цепочки (256-байтные чанки), DBSCHEMA
(типы полей, привязка таблица↔объект по порядку коллекций), конфигурация 8.1-эпохи
(GUID-файлы zlib + root). Поддержка обоих стилей имён таблиц: `_REFERENCE3` и
`_Reference74`. Интеграция в `read_metadata()` (модель `model.py`) и `table_rows()`.
Тул `status` в `mcp_server`: состояние коннекторов, кеша, пайплайна (адаптированная
идея 1C:Platform Tools MCP). Чтение реальных баз — только read-only.

## Scenarios

### Scenario: Каталог таблиц и метаданные базы 8.1-эпохи

- **When** `read_metadata('1C_8.1/1Cv8.1CD')`
- **Then** возвращает непустую модель: справочники/документы/перечисления/регистры с
  именами и синонимами, полями и типами; для справочника «Банки» привязка
  Reference3 → таблица `_REFERENCE3`.

### Scenario: Чтение строк реальной таблицы

- **When** `read_table('1C_8.1/1Cv8.1CD', '_REFERENCE3')`
- **Then** итератор отдаёт ≥ 1000 записей (реальная база: 1141 запись — банки
  Узбекистана); поля декодированы корректно (строки UTF-16LE, числа, даты, GUID);
  чтение потоковое (без загрузки всей базы в память).

### Scenario: Оба стиля имён таблиц

- **When** каталог таблиц парсится для `1C_8.1` (эпоха 8.1, `_REFERENCE3…`) и для
  `1C_8.3` (`_Reference74…`, camelCase)
- **Then** оба набора имён принимаются и сопоставляются с объектами конфигурации;
  для `1C_8.3` читается только каталог/схема (структура), конфигурация не требуется.

### Scenario: Тул status

- **When** агент вызывает `status` до/после шагов пайплайна
- **Then** возвращает: состояние коннекторов (файл: путь/размер/версия 1CD; HTTP:
  доступен/ошибка; SQL: не настроен), кеша (корень, записей, байт), пайплайна
  (проект, пара «1→1», последний шаг, успех).

### Scenario: Целостность и безопасность

- **When** парсер работает на реальной базе
- **Then** база открыта read-only; ошибки формата — исключение `FormatError` с
  осмысленным сообщением; некорректные/усечённые цепочки не приводят к падению
  процесса (исключение наружу, состояние парсера не портится).
