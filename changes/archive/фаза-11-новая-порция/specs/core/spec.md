# Spec: core

## Purpose
Реализовать Фазу 11 «Новая порция идей»: пересмотреть блок-лист в docs/ideas.md (раздел «Не взято и почему») и выбрать 2–3 идеи, ставшие применимыми после фаз 7–10 (консоль запросов конфигураций, сравнение ИБ по GUID, история версий конфигурации). Кандидаты: (1) консоль запросов конфигураций — выборка по метаданным/структуре конфигурации с SQL-подобными фильтрами поверх уже существующих парсеров; (2) сравнение ИБ по GUID — сверка ссылочных полей двух баз (источник/приёмник) по GUID для проверки полноты переноса; (3) история версий конфигурации — чтение ConfigDumpInfo/версий конфигурации 8.3. Для каждой выбранной идеи: реализация авторским кодом с unit-тестами (pytest), интеграция в CLI (argparse) и/или MCP-тулы, обновление docs/ideas.md (новые кандидаты с обоснованием и источником) и README (раздел «Фаза 11» со статусами). Ворота: pytest, mypy strict, ruff, vitest (Orion shield). Python 3.11+, Windows, реальные базы read-only. Только stdlib, без новых зависимостей.
