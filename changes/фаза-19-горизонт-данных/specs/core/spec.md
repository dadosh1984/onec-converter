# Spec: core

## Purpose
Фаза 19 — горизонт данных: расширить прямую запись до полноты переноса
(регистры), выровнять Module.bsl (replace, документы), задокументировать
ограничения (пустые таблицы, 1Cv8.dt).

## Requirements
- [REQ-1] Регистры (сведений/накопления/бухгалтерии) записываются через
  load_direct; e2e-тест на синтетике.
- [REQ-2] Module.bsl: обработка `replace` (поиск по коду/номеру → обновление,
  Обновлено>0); поддержка `Документ.*`; GET /metadata включает Документы.
- [REQ-3] docs/format-8x.md: разделы «Регистры (Фаза 19)», «Пустые таблицы
  (data_page=0) — ограничение».
- [REQ-4] Ворота зелёные: pytest, ruff, mypy strict, vitest; обратная
  совместимость.
