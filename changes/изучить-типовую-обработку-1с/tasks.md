# Задачи — изучить-типовую-обработку-1с

Легенда статусов: отмеченный квадрат означает готово, пустой — открыто;
forge переключает каждый квадрат по мере выполнения задачи.

## Контекст (факт проверки)

Типовая «Выгрузка и загрузка данных XML.epf» — на деле **xlsx-мост**
(работа через Excel), не XML-формат выгрузки 1С. Настоящего XML-выгрузчика
в нём нет; xlsx-мост уже воспроизведён в onec_converter (Фаза 3).
Поэтому «XML-мост» вынесен в опцию (п.4 «Оставшиеся этапы»), а данное
изменение закрывает реальную открытую задачу ядра переноса — **поддержку
перечислений в xlsx-мосте (`Перечисление.X` → `_Enum<N>._IDRREF`)**.

`_Enum<N>` хранит только `_IDRREF`+`_ENUMORDER`; имена/синонимы значений —
в CONFIG-скобкофайле объекта перечисления. Проверено на реальной базе
`1C_8.1`: 35 значений, позиционно 35/35 совпадение с таблицей; синонимы
различимы после `enum_mapper.normalize_enum_name`.

## Задачи

- [x] [assumption] Экстрактор значений перечисления из CONFIG приёмника:
      `extract_enum_values(db, full_name)` -> список `[(name, ru_synonym)]`
      в порядке `_ENUMORDER` (через `Database1CD`.config_get, `parse_bracket`,
      распил значения-GUID).
- [x] [assumption] Конвертация GUID-строки из CONFIG в 16 байт `_IDRREF`
      (layout `p3+p4+p2+p1+p0` — проверено на реальной базе).
      Обеспечить позиционное соответствие index → idrref с таблицей `_Enum<N>`.
- [x] [assumption] Индекс перечислений в мосте: синоним (нормализованный
      `normalize_enum_name`) -> `_IDRREF` приёмника для `Перечисление.X`.
- [x] [assumption] Ветка `Перечисление.X` в `epf_load._resolve_ref`:
      текст-синоним -> ссылка (вместо поиска по полям справочника):
      не найдено -> 16 нулей + ошибка строки в отчёте.
- [x] [fact] Обратный контроль/сверка перечисления: `EnumResolver.by_ref`
      (link -> синоним, реализован и покрыт тестом). Полная интеграция в
      `bridge_verify` требует экспорта реквизита-ссылки с именем типа
      (мета `read_metadata` несёт только `type='ref'` без полного имени) —
      вынесено за рамки этого изменения как пред-существующий пробел.
- [x] [assumption] Покрыть тестами: извлечение значений (фейковая ИБ),
      разрешение синоним -> ссылка, позиционность с `_Enum<N>`, e2e через мост.
- [x] [assumption] Прогнать ворота (`npm run lint/typecheck/test`) и
      `orion shield`; обновить README/команды, пункт 1.3 закрыть.
